一、数据结构（DS）核心知识点
1. 线性表
顺序表：插入、删除、查找的时间复杂度；扩容机制；优缺点
单链表：头插、尾插、删除、反转、环检测（快慢指针）
双链表、循环链表结构特点
静态链表（数组模拟）
线性表的应用：多项式相加、约瑟夫环
2. 栈和队列
栈：表达式求值（后缀 / 前缀）、括号匹配、递归转非递归
队列：循环队列（判空判满条件）、双端队列
栈与队列的应用：迷宫、层次遍历、BFS
3. 串
朴素匹配、KMP（next 数组、nextval 数组）
KMP 时间复杂度 O (n+m)
串的存储：顺序、块链
4. 树与二叉树
二叉树性质：第 i 层最多节点、高度 h 最多节点、n0=n2+1
完全二叉树、满二叉树、平衡二叉树
遍历：前 / 中 / 后 / 层序；由两种遍历恢复二叉树
线索二叉树：前驱后继、线索化
二叉排序树 BST：插入、删除、查找、平均查找长度 ASL
平衡二叉树 AVL：四种旋转（LL/RR/LR/RL）、高度差
哈夫曼树：构造、WPL、哈夫曼编码（前缀码）
5. 图
存储：邻接矩阵、邻接表、十字链表、邻接多重表
遍历：DFS（递归 / 非递归）、BFS
最小生成树：Kruskal（并查集）、Prim
最短路径：Dijkstra、Floyd、Bellman-Ford
拓扑排序、关键路径（AOE 网）
6. 查找
顺序查找、折半查找（判定树、ASL）
分块查找（索引顺序查找）
哈希表：哈希函数、冲突处理（链地址 / 开放地址）、装填因子
B 树、B + 树：结构、插入删除、查找过程
7. 排序（必考大题）
插入类：直接插入、希尔排序
交换类：冒泡、快速排序（划分、递归、非递归）
选择类：简单选择、堆排序（建堆、调整）
归并类：二路归并
基数排序（桶排序思想）
稳定性、时间 / 空间复杂度对比表（必须背）

二、计算机组成原理（CO）核心知识点
1. 计算机系统概述
冯・诺依曼体系：五大部件、存储程序
层次结构：微程序→机器语言→操作系统→高级语言
性能指标：CPI、MIPS、FLOPS、加速比
2. 数据表示与运算
进制转换、原码 / 反码 / 补码 / 移码
补码加减、溢出判断（双符号位、进位判断）
定点数、浮点数（IEEE754：单精度 / 双精度）
加法器、超前进位加法器
乘法：原码一位乘、补码一位乘（Booth）
除法：恢复余数、不恢复余数
浮点数加减：对阶→尾数加减→规格化→舍入
3. 存储器层次结构
层次：寄存器→Cache→主存→辅存
主存：SRAM/DRAM、刷新、地址线 / 数据线计算
主存扩展：位扩展、字扩展、字位扩展
双口 RAM、多模块存储器（高位 / 低位交叉）
Cache：映射方式（直接 / 全相联 / 组相联）
Cache 替换算法：FIFO、LRU、LFU
Cache 写策略：写直达 / 写回、写分配 / 非写分配
虚拟存储器：页式、段式、段页式；TLB、缺页中断
4. 指令系统
指令格式：操作码、地址码
寻址方式：立即、直接、间接、寄存器、寄存器间接、相对、基址、变址、堆栈
CISC vs RISC
指令流水线：冒险（结构 / 数据 / 控制）、解决方法（停顿、转发、分支预测）
5. 中央处理器 CPU
数据通路：ALU、寄存器、内部总线
控制器：硬布线、微程序（微指令、微命令、下地址）
中断：中断响应、中断屏蔽、中断优先级、中断向量
异常与系统调用
6. 总线与 I/O
总线分类：片内、系统、I/O
总线仲裁：链式查询、计数器、独立请求
总线定时：同步、异步、半同步
I/O 方式：程序查询、中断、DMA、通道
DMA：请求、响应、传输、结束；与 CPU 访存冲突

三、操作系统（OS）核心知识点
1. 操作系统概述
功能：管理软硬件、提供接口
结构：整体、分层、微内核、外核
内核态 / 用户态、系统调用
2. 进程管理
进程 vs 线程
进程状态：就绪、运行、阻塞、创建、终止
PCB、进程控制（fork/exec/wait/exit）
线程实现：内核级、用户级、混合
进程通信：管道、消息队列、共享内存、信号量、套接字
3. 处理机调度
调度层次：高级、中级、低级
调度算法：FCFS、SJF、SRTF、RR、优先级、多级反馈队列
调度指标：周转时间、带权周转、响应比
4. 同步互斥
临界区、互斥、同步、死锁
信号量：P/V 操作、生产者 - 消费者、读者 - 写者、哲学家进餐
管程、条件变量
死锁：必要条件、处理策略（预防 / 避免 / 检测与解除）
银行家算法（必背大题）
5. 内存管理
连续分配：单一连续、固定分区、动态分区（首次 / 最佳 / 最坏适应）
非连续：分页、分段、段页式
虚拟内存：请求分页、页面置换算法（OPT/FIFO/LRU/LFU/Clock）
抖动、工作集、页表、快表 TLB
6. 文件管理
文件结构：顺序、索引、链式
目录结构：单级、两级、树形、无环图
外存分配：连续、链接、索引（混合索引）
空闲空间管理：位图、空闲表、空闲链、成组链接
文件系统：FAT、NTFS、EXT
7. I/O 管理
I/O 软件层次：用户层→设备无关→驱动→中断
设备分配：SPOOLing、设备独立性
磁盘调度：FCFS、SSTF、SCAN、CSCAN、FSCAN

四、计算机网络（CN）核心知识点
1. 网络体系结构
OSI 七层、TCP/IP 四层
封装与解封装、PDU
性能指标：带宽、时延、吞吐量、利用率
2. 物理层
传输介质：双绞线、光纤、同轴电缆
编码：曼彻斯特、差分曼彻斯特、NRZ
多路复用：FDM、TDM、STDM、WDM、CDMA
交换：电路交换、报文交换、分组交换
3. 数据链路层
组帧：字符填充、零比特填充
差错控制：CRC、海明码
流量控制：停等、GBN、SR
介质访问：ALOHA、CSMA/CD（以太网）、CSMA/CA（WiFi）
以太网：MAC 地址、帧格式、交换机、VLAN
PPP、HDLC
4. 网络层
路由算法：距离向量（RIP）、链路状态（OSPF）、BGP
IP 协议：IPv4 地址、子网划分、CIDR、最长前缀匹配
ARP、DHCP、ICMP（ping/tracert）
NAT、VPN
IPv6：地址格式、改进点
5. 传输层
UDP：特点、校验和
TCP：三次握手、四次挥手、可靠传输机制
TCP 流量控制：滑动窗口、糊涂窗口
TCP 拥塞控制：慢启动、拥塞避免、快重传、快恢复
端口号、套接字
6. 应用层
DNS：递归 / 迭代、记录类型（A/AAAA/CNAME/MX）
FTP：主动 / 被动模式
HTTP/HTTPS：请求方法、状态码、Cookie/Session、HTTP2/3
Email：SMTP、POP3、IMAP
P2P、CDN
